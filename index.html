Awesome Open-Source Web Apps

A curated list of open-source web server applications and tools built with web technologies.

Contributions are welcome via PR, and I will feature your app on my social media account (𝕏).

Tools & Utilities

  • LibreDB Studio - A web-based database IDE that runs alongside your databases and supports 16 database systems.
  • TLSFlow - Automates SSL/TLS certificate renewals with verification and rollback.
  • Dub - Open-source link attribution for short links, conversion tracking, and affiliate programs.
  • Syncthing - Continuously syncs folders between multiple computers with a web interface.

Networking & Proxy

  • rathole - A lightweight reverse proxy for secure, high-performance NAT traversal.
  • frp - A high-performance reverse proxy for NAT traversal over TCP and UDP.
  • nps - A lightweight, high-performance intranet penetration proxy server with a powerful web management terminal.
  • Chisel - A fast TCP/UDP tunnel over HTTP secured via SSH, useful for passing through firewalls.
  • pgrok - A poor man's ngrok: multi-tenant HTTP/TCP reverse tunnel solution via SSH port forwarding.
  • PendingDNS - A lightweight authoritative DNS server with API-driven configuration.

Data & Streaming

  • Memphis - A highly scalable and effortless data streaming platform for real-time data processing.
  • NocoDB - Turns MySQL, PostgreSQL, SQLite and other databases into a smart spreadsheet.
  • Zinc - A lightweight full-text search engine and Elasticsearch alternative with a web UI.
  • Plausible - A lightweight, self-hosted web analytics and an open-source Google Analytics alternative.
  • Sonic - A fast, lightweight search backend that can serve as an Elasticsearch alternative.

Documentation & Wiki

  • Docmost - An open-source collaborative wiki and documentation software, an alternative to Confluence and Notion.
  • Think - A self-hosted knowledge management tool with collaborative documents.

Server & Self-Hosting

  • Umbrel - An elegant home server OS with an app store of over 300 self-hosted apps.
  • SFTPGo - A full-featured SFTP server for setting up secure encrypted file transfer services.
  • KubeSphere - An enterprise container management platform built on Kubernetes with an easy-to-use web console.
  • Peekd - A lightweight single-binary web file server for browsing and sharing local files.
  • Fogshare - Self-hosted file sharing and static-site hosting with short links and access controls.

Business & Office

  • Odoo - Open-source business apps covering CRM, eCommerce, inventory, project management, and accounting.
  • Chatwoot - An open-source live chat software, an alternative to Intercom, Zendesk and Crisp.
  • Rocket.Chat - A feature-rich team chat platform and one of the best open-source Slack alternatives.
  • Chat - An instant messaging platform with web, iOS, Android and command-line clients.
  • listmonk - A self-hosted newsletter and mailing list manager with a web admin panel.
  • EdenText - A local, privacy-first web word processor for docx and odt files, no account needed.
  • ResumeForge - A local-first AI resume builder, job tracker and interview prep workspace.

Development Tools

  • Phoenix - A web-based code editor built on Brackets that can be used as an online IDE.
  • CodeFever - An open-source self-hosted Git code hosting service.
  • Appwrite - A self-hosted backend platform with auth, databases, storage, functions and more.
  • OneDev - A self-hosted DevOps platform with Git hosting, issue tracking, pull requests and CI.
  • Verdaccio - A simple, zero-config private npm registry for local package proxying.
  • code-server - Runs VS Code on a remote server, accessible from your browser.
  • Drone - A container-native continuous integration platform built on Docker.
  • Super Inspire - Run a Linux container via Docker and access it from your browser.
  • tapflow - Run iOS simulators and Android emulators in your browser, a self-hosted Appetize alternative.

Media & Entertainment

  • Jellyfin - A free media system to manage and stream your media, an alternative to Emby and Plex.
  • Navidrome - An open-source music streaming server with a web interface for managing your music.
  • Pixelfed - A federated photo sharing service and an open-source Instagram alternative.
  • jellyfin-rust - A reimplementation of the Jellyfin server compatible with Jellyfin and Emby clients.
  • RA2 VM - Run the original Red Alert 2 and Yuri's Revenge directly in your browser.
  • Video Transcript - Edit and burn video subtitles entirely in your browser, with local processing only.
  • OpenSubs - Generate, translate and burn video subtitles in your browser without uploading any files.

Design & Creativity

  • Penpot - The open-source design and prototyping platform for product teams.

Finance & Payments

  • Monero Web Wallet - A self-hosted Monero web wallet with no third-party servers and no telemetry.
