精选 Web 开源应用

本列表精选各类使用 Web 技术开发的开源 Web 服务端应用与工具

欢迎通过 PR 提交你的开源项目，我会在我的社交媒体账号 (𝕏) 上推荐你的应用。

工具与实用程序

  • LibreDB Studio - 部署在数据库旁的 Web 数据库 IDE，支持 16 种数据库。
  • TLSFlow - 自动化管理 SSL/TLS 证书更新，支持验证与回滚。
  • Dub - 开源的链接归因平台，支持短链接、转化跟踪和联盟计划。
  • Syncthing - 多台电脑之间自动同步文件夹的工具，提供 Web 图形界面。

网络与代理

  • rathole - 轻量级反向代理，用于安全、高性能的内网穿透。
  • frp - 高性能反向代理，用于 TCP、UDP 内网穿透及 HTTP/HTTPS 应用代理。
  • nps - 轻量级、高性能的内网穿透代理服务器，支持多种流量转发，带有 Web 管理端。
  • Chisel - 基于 HTTP 传输、SSH 加密的快速 TCP/UDP 隧道工具，常用于穿透防火墙。
  • pgrok - 平替版 ngrok：基于 SSH 远程端口转发的多租户 HTTP/TCP 反向隧道方案。
  • PendingDNS - 轻量级权威 DNS 服务器，可通过 API 修改设置。

数据与流处理

  • Memphis - 开源的高可扩展实时数据流处理平台，让数据流处理变得轻松简单。
  • NocoDB - 将 MySQL、PostgreSQL、SQLite 等数据库转换为智能电子表格。
  • Zinc - 轻量级全文搜索引擎，Elasticsearch 替代品，自带 Web 管理界面。
  • Plausible - 轻量级自托管网站访问统计分析，Google Analytics 开源替代品。
  • Sonic - 快速轻量的搜索后端服务，可用作 Elasticsearch 替代品。

文档与知识库

  • Docmost - 开源协作式 Wiki 与文档软件，可替代 Confluence 和 Notion。
  • 云策文档 Think - 开源知识管理工具，支持自部署和多人协作文档。

服务器与自托管

  • Umbrel - 优雅的家庭服务器操作系统，内置 300 多款自托管应用的应用商店。
  • SFTPGo - 功能齐全的 SFTP 服务器，可架设加密的 FTP 文件传输服务。
  • KubeSphere - 基于 Kubernetes 的企业级多租户容器管理平台，提供易用的 Web 操作界面。
  • Peekd - 轻量级单二进制 Web 文件服务器，用于快速浏览和共享本地文件，支持丰富格式预览。

商业与办公

  • Odoo - 开源商业应用套件，涵盖 CRM、电商、库存、项目管理和会计等。
  • Chatwoot - 开源实时客服聊天软件，可替代 Intercom、Zendesk、Crisp 等。
  • Rocket.Chat - 功能丰富的团队聊天平台，特性最多的 Slack 开源替代品之一。
  • Chat - 即时消息传递平台，提供 Web、iOS、Android 及命令行客户端。
  • listmonk - 自托管新闻邮件与邮件列表发送服务，带有管理后台。
  • EdenText - 本地运行的隐私优先 Web 文字处理器，支持 docx 和 odt，无需账号。
  • ResumeForge - 本地优先的 AI 简历工作台：简历定制、求职追踪与模拟面试，数据不出本机。

开发工具

  • Phoenix - 基于 Brackets 打造的 Web 版代码编辑器，可当作线上 IDE 使用。
  • CodeFever - 开源自托管的 Git 代码托管服务程序。
  • Appwrite - 自托管后端云平台，提供认证、数据库、存储、函数等服务。
  • OneDev - GitLab 替代品：自托管 DevOps 平台，支持 Git 托管、issue 追踪、PR 和持续集成。
  • Verdaccio - 简单零配置的本地私有 npm 仓库，可用于包代理。
  • code-server - 在远程服务器上运行 VS Code，可通过浏览器访问。
  • Drone - 基于 Docker 的容器化持续集成平台。
  • Super Inspire - 用 Docker 启动 Linux 容器，并可通过浏览器直接访问该系统。

媒体与娱乐

  • Jellyfin - 免费开源媒体系统，用于管理和流式传输你的媒体，可替代 Emby 和 Plex。
  • Navidrome - 开源音乐流媒体服务器，提供 Web 管理界面管理自己的音乐文件。
  • Pixelfed - 联邦式照片分享服务，Instagram 的开源替代品，可与其他平台互通。
  • jellyfin-rust - Jellyfin 服务端的重新实现，兼容 Jellyfin 与 Emby 客户端。
  • RA2 VM - 浏览器直接运行的《红色警戒2》与《尤里的复仇》原版网页游戏，支持多人联机。
  • Video Transcript - 浏览器中完成视频字幕编辑与烧录，全程本地处理，支持本地自动识别生成字幕。

设计与创意

  • Penpot - 面向产品团队的开源设计与原型协作平台。

金融与支付

  • Monero Web Wallet - 自托管的 Monero 网页钱包，无需第三方服务器、不收集遥测数据。
